## ❌ 2. Rifas Proibidas

🚫 Itens e Práticas Proibidas:

Para garantir a segurança e a viabilidade da plataforma, é estritamente proibido criar rifas ou sorteios que envolvam:

Veículos Automotores: Incluindo, mas não se limitando a, carros, motos e scooters.

Peças e Acessórios: Pneus, peças de reposição ou componentes mecânicos.

Turismo: Pacotes de viagens, passagens aéreas ou hospedagens.

Itens de Luxo: Joias, pedras preciosas e relógios de alto valor.

### 2.1 Conteúdo Ilegal
```
🚫 Armas de fogo ou munição
🚫 Drogas ou substâncias controladas
🚫 Explosivos ou materiais perigosos
🚫 Contrabando
🚫 Itens roubados ou falsificados
```
### 2.2 Conteúdo Restrito
```
⚠️ Álcool (apenas com CPF verificado)
⚠️ Cigarros (apenas com CPF verificado)
⚠️ Medicamentos controlados (requer receita)
⚠️ Produtos de beleza (cosmética)
⚠️ Criptomoedas (estritamente proibido)
```

### 2.3 Conteúdo Ofensivo
```
🚫 Conteúdo sexual explicito
🚫 Violência ou gore
🚫 Discurso de ódio
🚫 Assédio ou intimidação
🚫 Conteúdo que incita crimes
```

### 2.4 Propriedade Intelectual
```
🚫 Produtos falsificados
🚫 Software pirata
🚫 Conteúdo com direitos autorais
🚫 Marcas registradas não autorizadas
```

### 2.5 Esquemas Fraudulentos
```
🚫 Pirâmides ou esquemas Ponzi
🚫 Ganhos fáceis "comprovados"
🚫 Duplicação de dinheiro
🚫 Investimentos garantidos
🚫 Rifas sem sorteio real
```

## 2.6 Perigos

```
🚫 Animais vivos
🚫 Órgãos humanos
🚫 Dados pessoais alheios
🚫 Documentos falsificados
```

## 🎲 5. Sorteios Justos

### 5.1 Critérios de Transparência

```
✓ Sorteio deve ser aleatório
✓ RNG certificado (entropy)
✓ Resultado transmitido ao vivo (opcional)
✓ Vencedor pode ser verificado
✓ Não pode influenciar o resultado
```

### 5.2 Como Realizamos Sorteios
```
1. Coletamos todos os números vendidos
2. Usamos gerador aleatório criptográfico
3. Selecionamos 1 número aleatoriamente
4. Registramos evento (imutável)
5. Notificamos vencedor
```

### 5.3 Disputas de Sorteio
Se questionar resultado:
```
1. Solicite revisão em 48h
2. Fornecemos logs do sorteio
3. Terceiro neutro arbitra se necessário
4. Decisão é final
```

## 🚫 6. Violações e Punições

### 6.1 Escala de Punições

```
NÍVEL 1 - Aviso Verbal
├─ Descrição incompleta
├─ Imagem de baixa qualidade
└─ Resposta lenta a mensagens

NÍVEL 2 - Aviso Escrito (24h)
├─ Não entregar em 60 dias
├─ Descrição enganosa
├─ Múltiplos avisos verbais
└─ Comunicação ofensiva

NÍVEL 3 - Suspensão 7 dias
├─ Rifa cancelada sem causa
├─ Não entregar prêmio
├─ Ameaças a usuários
├─ Tentativa de fraude
└─ Múltiphos avisos escritos

NÍVEL 4 - Suspensão 30 dias
├─ Rifa fraudulenta comprovada
├─ Sorteio não realizado
├─ Dados de usuários vazados
└─ Atividade criminal suspeita

NÍVEL 5 - Banimento Permanente
├─ Atividade ilegal confirmada
├─ Fraude em múltiplos sorteios
├─ Exploração de sistema
├─ Inciência de violações após suspensão
└─ Denúncia policentral
```

### 6.2 Processo de Apelação
```
1. Você recebe aviso de violação
2. Tem 7 dias para responder
3. Revisamos sua resposta
4. Você recebe decisão final
5. Pode apelar ao ombudsman
```
