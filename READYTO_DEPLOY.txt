🚀 COMO COMEÇAR (5 PASSOS)
═══════════════════════════════════════════════════════════════════════════════

1️⃣  INSTALAR DEPENDÊNCIAS
    ──────────────────────
    $ cd backend
    $ npm install

2️⃣  GERAR CHAVES DE SEGURANÇA
    ──────────────────────────
    $ node generate-security-keys.js
    
    Saída esperada:
    ✅ JWT_SECRET (32 bytes hex)
    ✅ JWT_REFRESH_SECRET (32 bytes hex)
    ✅ ENCRYPTION_KEY (32 bytes hex)
    ✅ SESSION_SECRET (32 bytes hex)

3️⃣  CONFIGURAR VARIÁVEIS DE AMBIENTE
    ────────────────────────────────
    $ cp .env.example .env
    
    Editar .env e adicionar:
    - JWT_SECRET (do passo 2)
    - ENCRYPTION_KEY (do passo 2)
    - SESSION_SECRET (do passo 2)
    - MONGODB_URI (sua conexão)
    - FRONTEND_URL (seu domínio)

4️⃣  INICIAR SERVIDOR
    ─────────────────
    Desenvolvimento:
    $ npm run dev
    
    Produção:
    $ npm start

5️⃣  LER DOCUMENTAÇÃO
    ─────────────────
    $ cat backend/SECURITY.md
    $ cat backend/IMPLEMENTATION_GUIDE.md
